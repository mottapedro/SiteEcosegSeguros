# Repositório Jurídico — ECOSEG

## Finalidade

Este diretório governa evidências jurídicas utilizadas pela ECOSEG em conteúdo público, palestra e inteligência consultiva.

## Regra de autoridade

Fontes primárias oficiais prevalecem. Materiais de terceiros podem ser registrados como fontes de descoberta, mas não se tornam autoridade jurídica do projeto.

Cada registro deve separar: fato jurídico, fonte primária, ressalvas, formulação editorial autorizada, formulações não suportadas e rastreabilidade.

## Registros

- `MIL-REM-001` — Adicional de Compensação por Disponibilidade Militar / Tema 1175 STF.
- `MIL-PEN-001` — Pensão militar para filhas / regra de transição.

## Gate de publicação

Um conteúdo jurídico somente pode ser consumido pela superfície pública quando seu registro estiver validado para esse uso. A apresentação não é fonte da verdade jurídica; ela referencia registros governados.
